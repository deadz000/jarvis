# 决策清单（v0.1）

> **用途**：把「谁决定了什么」写清楚，避免两类失控：
> ① 待决策项被实现细节悄悄固定下来；② 产品语义被工程师按最省事的方式默认。
>
> **来源**：项目需求规格说明书 §11（13 项待决策）+ 实施计划各里程碑 + M0–M3 开发过程中实际发生的决定。
> **更新规则**：任何一项状态变更都必须同步本表；「已由开发默认」不等于「已确认」。

| **并发上限默认 4** | 计划要求"配置化、不沿用旧项目数值"，我选了一个中性值 | 易（改配置） |
| **准入策略为 FIFO，不做优先级/饥饿防护** | 最小复杂度，计划把优先级列为待决策 | 中（要改 Scheduler 内核） |
| **ADR-002 把 M3 的候选状态机冻结为规范** | SRS §4.1 写明是「候选状态，待 PoC 验证」，我用穷举测试把它固化了 | **中** —— 现在改成本最低（24 项测试） |

## 屏幕观察规格（2026-10-10 项目负责人确认）

| 项 | 决定 |
|---|---|
| 开关 | **必须有显式开关**；关闭时完全不采集 |
| 原始帧 | **一律不落盘**。实现上更进一步：帧连业务进程的堆都不进（.NET 侧截屏+降采样后立即丢弃位图，只回传 64 个灰度值 + 768 个色块通道值） |
| 摘要步骤的隐私含义 | ⚠️ **摘要会把一张降采样图（约 35KB JPEG）发送给模型 API**。这与「帧不落盘」是**两个不同的保证**：不写磁盘仍然成立，但该图确实离开了本机。缓解措施：图**只在攒批出批时物化一次**，不在每轮轮询产生；默认关闭开关；意图门控让纯文字指令完全不触发。 |
| 变化过滤 | **双条件 AND**：`pHash(64bit 中值指纹)` **AND** `大面积色块变化` |
| 节流 | **5 秒** |
| LLM 摘要 | **攒批 3 帧 / 5 分钟**一次（5 分钟是上限而非周期，攒够 3 帧立即出批） |
| 摘要去向 | 进 **10 分钟滑动窗口**，作为 Master 的屏幕上下文 |
| 意图门控 | **纯文字指令零成本**：不命中屏幕指代词时不注入任何屏幕内容 |
| 按需截图 | Worker 可调用截图工具主动获取当前画面；**本期先留空**（见下方遗留） |

> ⚠️ **与实施计划 §9 的张力（已由产品负责人拍板）**
> 实施计划「首版不做清单」写明「不以历史 CclawCore 的参数直接定义新系统阈值」。
> 上面的阈值（5s / 3 帧 / 5 分钟 / 10 分钟）与旧项目参数一致。
> 区别在于：这次是**产品负责人显式选择**，而不是开发静默沿用 —— 该警戒针对的是后者。
> 但这些阈值**仍是未经验证的启发式**，M8 应结合真实使用数据重新评估。

## 当前质量基线（供决策参考）

> 更新于 2026-10-10（M6a 语音输出侧完成 + M6b 语音输入闭环 + M6d 屏幕过滤链）

- `tsc --noEmit` 干净；**234 项单元测试通过**（原记录 64 项，已过期）
- 6 个实测脚本实跑通过：`example:sdk` / `example:abort` / `example:workers` / `example:lifecycle` / `example:master` / `example:tts` / `example:asr`
- **真实屏幕采集实测通过**：1920x1080，333–344ms/帧，静止画面无误报（汉明距离 0 被正确拒绝）
- **真实多模态摘要实测通过**：1024x576 JPEG（约 35KB），约 2.7s，摘要内容准确
- **屏幕观察端到端实测通过**：开关 → 采集 → 过滤 → 攒批 → 摘要 → 10 分钟窗口 → 门控注入（30s 内产出 3 条摘要）
- **语音输入闭环实测通过**：63 帧 / 198720 字节 / 6.21s 音频 → 9 条中间结果 + 1 条终稿 → 自动创建任务并执行成功
- **真实服务实测通过**：
  - `example:tts`：真实 TTS，51 字 → 18 分片 / 424800 字节，首音频 **565ms**，反推 0.174 秒/字（证实 PCM 16-bit LE 单声道假设）

- 端到端实测：结果 → 交付策略 → 真实 TTS → SSE → 浏览器 `AudioContext` 播放（SSE 客户端收到 28 帧 / 716640 字节 / 14.93s 音频）
- 已实测确认：真实模型调用、自定义工具闭环、`abort` 传递到工具层、真实双 Session 并行重叠 1818ms、上下文隔离、取消隔离、旧代次分片被拒绝、面板脚本载入期无异常
